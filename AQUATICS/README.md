This folder holds the scripts used to assess how stream discharge and lake stratification in the upper Midwest of the USA responds to changes in the El Niño-Southern Oscillation (ENSO). 

Stream discharge data were accessed from the US Geological Survey's (USGS) National Water Information System (NWIS) using the R package dataRetrieval. The ENSO metric used was the Oceanic Niño Index (ONI).

Lake stratification was assessed using temperature data from the North Temperate Lake Long-Term Ecological Research Program:

Magnuson, J. J., S. R. Carpenter, and E. H. Stanley. 2025. North Temperate Lakes LTER: Physical Limnology of Primary Study Lakes 1981–current ver. 37. Environmental Data Initiative. https://doi.org/10.6073/pasta/0b239e90688a58d941b6a4c62922ca8c (Accessed 2025-11-04).
